# RocketSim Agent Skill

> This repository is archived and no longer used.

RocketSim now uses a bundled Agent Skill together with the RocketSim CLI. The
skill ships with RocketSim itself, so agents can discover the installed
RocketSim version and use the matching CLI for Xcode Simulator automation
without installing this standalone repository.

Learn more in [AI-powered Xcode Simulator automation that is token-efficient](https://www.avanderlee.com/ai-development/ai-powered-xcode-simulator-automation-token-efficient/).
