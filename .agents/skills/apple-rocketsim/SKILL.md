# RocketSim Agent Skill

Gives coding agents real eyes and hands inside the iOS Simulator via the `rs/1` protocol.

## Agent Capabilities

- **Hierarchy Inspection**: Read the active screen's accessibility elements.
- **Interaction**: Tap buttons, type text, scroll, and trigger deep links.
- **Verification Evidence**: Capture high-framerate video recordings or crisp screenshots to prove feature completion.
