## 🔑 Key Breakthroughs & Technical Decisions

### 1. Differentiating the Three Distinct Composer Styles (`MessageComposerStyle.swift`)
To prevent conflating disparate AI interaction surfaces, we formalized strict geometric boundaries:
- **`Classic Glass`**: Single-row pill (`cornerRadius: 22`) paired with an external, detached 44×44pt glass circle for attachments (`+`). Model selection is housed inside the pill as a compact 32×32pt icon button. Designed for classic mobile timelines (iMessage / Sofia).
- **`Card Glass`**: Two-row structured card (`cornerRadius: 24`, resting height ~84pt) designed for canvas/desktop workflows (Craft Assistant). Restored optical equilibrium by giving the leading attachment button an explicit 32×32pt circular background (`Color.primary.opacity(0.06)`) and stroke border, balancing the trailing 32×32pt primary send button.
- **`Compact Glass`**: Ultra-dense single-row capsule (`cornerRadius: 22`, resting height 44pt) with a borderless `+` button nested directly inside the capsule leading edge. Ideal for slide-over sheets, macOS inspectors, and secondary popovers.

### 2. Eliminating the "Permanent Dog-Bone" via Focus-Breathing Physics
Apple's Liquid Glass runtime calculates GPU Signed Distance Field (SDF) blending based on `GlassEffectContainer(spacing:)`, which defines the interaction radius $R_{\text{merge}}$.
- **The Anti-Pattern**: Setting `GlassEffectContainer(spacing: 28)` with static child spacing $d = 6\text{pt}$ forced a permanent blend factor of $\approx 0.78$ at rest ($d \ll R_{\text{merge}}$). The circular `+` button and the pill melted into an unsightly, static "dog-bone" before the user interacted with the view.
- **The Breakthrough**: We reduced `GlassEffectContainer(spacing: 8)` ($R_{\text{merge}} = 8\text{pt}$) and introduced dynamic layout focus-breathing:
  ```swift
  HStack(alignment: .bottom, spacing: configuration.isFocused ? 3 : 8)
    .animation(.spring(duration: 0.35, bounce: 0.15), value: configuration.isFocused)
  ```
  At rest ($d = 8\text{pt} \ge R_{\text{merge}}$), the blend factor is $0.0$, maintaining two crisp, independent glass surfaces. Upon focus ($d = 3\text{pt} < R_{\text{merge}}$), the elements enter the merge envelope under an authentic Apple spring, producing an organic fluid "kiss" that cleanly snaps back on keyboard dismissal.

### 3. Popover Presentation vs. Disappearing Pill Bug
SwiftUI's `Menu` delegates to UIKit's `UIContextMenuInteraction`, which captures an offscreen snapshot of the presenting view hierarchy (`UITargetedPreview`) and detaches its rendering layer. Within a `.glassEffectID` container, this layer removal broke the Metal refractive backbuffer graph, causing the entire composer pill to vanish and leave an orphaned floating menu.
- **Solution**: Replaced `Menu` with `.popover(isPresented:arrowEdge: .bottom)` configured with `.presentationCompactAdaptation(.popover)`. This attaches the menu as a lightweight overlay window while keeping the composer pill 100% visible, fully rendered, and anchored in place.

### 4. Continuous Curvature Insets & Bottom Baseline Anchoring
- **Text Insets**: In a 22pt rounded pill, standard 8pt padding causes top and bottom glyphs to intersect with the corner apex ($X_{\text{safe}} = r \cdot (1 - \cos\theta)$). Expanding insets to `14pt leading` and `10pt vertical` ensures text stays strictly within the rectangular inner safe zone.
- **Baseline Alignment**: Changed row stacking from `.center` to `HStack(alignment: .bottom)` with uniform 34pt control frame budgets (`.frame(width: 32, height: 32)`). Buttons remain anchored to the bottom baseline next to the send button regardless of prompt line count.

### 5. Multi-Turn Upward Scroll Push & Streaming Cadence
- In `ConversationView.swift`, `.onChange(of: turns.last?.id)` ensures that newly appended turns trigger top-anchored upward scroll positioning (`proxy.scrollTo(targetTurnID, anchor: .top)`) on the second and all subsequent conversational turns.
- Focusing the composer text field no longer triggers spurious timeline scrolls.
- `StreamingMarkdownView` token arrival logic updates `displayedCharacterCount` monotonically across incremental arrivals, avoiding token chunk stalls.

## 🚧 Blockers & Resolutions
- **Permanent Dog-Bone Shape Merge**:
  - *Obstacle*: Setting large container merge radii caused detached buttons to fuse into the text pill at rest.
  - *Resolution*: Replaced static container spacing with dynamic layout spacing (`spacing: isFocused ? 3 : 8`) inside `GlassEffectContainer(spacing: 8)`.
- **Disappearing Pill on Model Selection**:
  - *Obstacle*: UIKit context menu snapshotting unregistered the composer pill from the Liquid Glass Metal render pass, turning the pill completely transparent.
  - *Resolution*: Migrated model selection to `.popover(isPresented:arrowEdge: .bottom)` with `.presentationCompactAdaptation(.popover)`.
- **Corner Glyphs Clipping in Multiline Inputs**:
  - *Obstacle*: 2-line and 3-line drafts collided with the 22pt corner curvature.
  - *Resolution*: Calibrated text field insets to 14pt leading and 10pt vertical padding.
- **Button Float in Multiline Prompts**:
  - *Obstacle*: Auxiliary buttons floated mid-air when draft text wrapped across multiple lines.
  - *Resolution*: Applied `HStack(alignment: .bottom)` across all composer styles with fixed 32×32pt control footprints.
